Button in den Varianten von shadcn/ui; Höhe folgt der Dichte (--control-h), size="lg" ist der eine Primärknopf der Halle (72 px).

```jsx
<Button icon="Check">Bestätigen</Button>
<Button variant="outline">Verschieben</Button>
<Button variant="destructive" icon="XCircle">Abweisen</Button>
<Button size="lg" icon="LogIn">Check-in</Button>
```

Ein default-Button pro Screen. destructive nur für Abweisen/Ablehnen/Stornieren, immer mit Dialog.
